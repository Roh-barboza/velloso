# Velloso Cidadania — Redirect de contratos

Projeto mínimo para redirecionar o endereço público do Vercel para o formulário de contratos da Velloso Cidadania.

## Destino

https://forms.gle/XYKmKUTtBC9mhWev7

## Deploy no Vercel

Ao importar o repositório `Roh-barboza/velloso`, configure:

- Root Directory: `redirect-contratos`
- Project Name: `contratos-vellosocidadania`
- Framework Preset: Other
- Build Command: vazio
- Output Directory: vazio

O `vercel.json` faz o redirecionamento da raiz para o Google Forms.
